# Packman Filament (`axiomasoft/packman-filament`)

Filament 5 integration plugin (`PackmanFilamentPlugin`), Livewire/Filament surface & bulk-action security hooks (`RefusesSurfaceBoot`, `RefusesSurfaceCalls`, `RefusesEditableColumns`, `AuthorizesActions`, `RefusesUnverifiableDownload`), and stateless AES-encrypted `BindingEditor` form helpers for `axiomasoft/packman-panels`.
