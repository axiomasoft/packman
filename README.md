# Packman Panels (`axiomasoft/packman-panels`)

Headless panel descriptors and access catalogue (`PanelCatalogue`, `InMemoryPanelCatalogue`, optional `ModulePanelCatalogue`), two-phase `PanelRegistry` and append-only `PanelRecipe` builder (`PanelBuilder`, `Panel`, `PanelCatalog`, `PanelAdmission`), form/slot projection contracts (`PanelSlot`, `PanelFormData`, `PanelSubjects`, `PanelFormProjection`), and SQL-backed tenant `SavedViews`.
